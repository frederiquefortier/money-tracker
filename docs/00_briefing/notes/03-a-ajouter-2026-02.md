# À ajouter (13 et 14 février 2026)

Raw notes, kept verbatim. Feedback from testing the first prototype. The detailed prompts
written from these notes are in [04-prompts-de-correction.md](04-prompts-de-correction.md).

---

## 13 février

### COMPTE
- On devrait pouvoir rajouter une institution avec un nom et un lien (vers le site web de l'institution) que l'utilisateur peut sélectionner et réutiliser.
- Les comptes devraient être regroupé par institution.
- Les comptes doivent pouvoir être trier par type, solde + et solde -.

### PARTOUT
- La liste des devises doit provenir de l'api.
- La devise de l'interface devrait être facilement modifiable peut importe sur quel page on se trouve (soit un dropdown, comme pour un changement de langue)

## 14 février

### TRANSACTION
- Une transaction peut être un transfert d'un compte à un autre. Un transfert peut avoir des frais associés qui doivent compté comme une dépense.
- La devise devrait toujours être demandé pour une transaction.
- Les catégories en favoris devrait être dans un groupe mis de l'avant dans le sélecteur de catégorie.
- Une catégorie archivé ne devrait pas être disponible dans la liste des catégories.

### CATÉGORIES
- Les catégories archivés devraient être affichés ensemble, hors de la liste active.
- Il y a un popup qui parle de l'historique des catégories, mais cet historique est invisible.
- Les icônes de catégorie devrait avoir tous les emojis possibles. Utilise https://github.com/ealush/emoji-picker-react. Le style souhaité est celui de Google.
